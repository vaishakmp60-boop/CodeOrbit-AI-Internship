# CodeOrbit Tech AI Internship Projects

This repository contains my completed projects for the CodeOrbit Tech Artificial Intelligence Internship.

## Projects Included
1. **Rule-Based Chatbot (`CodeOrbit_Chatbot`)**: A Python chatbot using pattern matching and keyword parsing to handle conversational queries.
2. **Tic-Tac-Toe with AI (`CodeOrbit_TicTacToe`)**: A terminal-based game featuring an adversarial AI opponent designed to detect win conditions and block player moves.
3. **Image Classification (`CodeOrbit_ImageClassification`)**: A computer vision script utilizing a pretrained PyTorch MobileNetV2 model to classify images based on the ImageNet dataset.

## Technologies Used
* Python 3
* PyTorch & Torchvision
* Pillow (PIL)
* Regular Expressions (`re`)
* Built-in `random` and `time` modules

## Setup & Execution
Clone the repository and run the scripts from your terminal:

* **Chatbot:**
  `python CodeOrbit_Chatbot/chatbot.py`

* **Tic-Tac-Toe:**
  `python CodeOrbit_Chatbot/CodeOrbit_TicTacToe/tictactoe.py`

* **Image Classifier:**
  `python CodeOrbit_Chatbot/CodeOrbit_TicTacToe/CodeOrbit_ImageClassification/classifier.py`
